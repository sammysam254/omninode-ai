Deploy Host Agent (`setup.bat`)

Run this single script on any Windows, Mac, or Linux computer. It will automatically crawl local files, detect any connected Android phones via USB debugging, and sync all assets to this central Supabase hub.

git clone https://github.com/your-repo/agentai.git && cd agentai/agent && setup.bat
1. Go to Android Settings > About Phone > Tap "Build Number" 7 times to enable Developer Options.
2. Go to Developer Options > Turn ON "USB Debugging".
3. Connect Phone via USB cable to the PC running setup.bat.
4. Tap "Always allow from this computer" when prompted on your phone screen.
